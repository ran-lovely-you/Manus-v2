# manus-v2（無料版 HTML）
無料で使える AI チャットアシスタント Web アプリケーション（HTML 単一ファイル版）

🤖 特徴
完全無料 - 登録不要、ネット接続ですぐ使える
ローカル動作 - すべての計算は端末内で完結
AI チャット - Claude API キーを入力すれば AI と会話できる
シンプルな UI - 使いやすいデザイン
履歴保存 - ブラウザの履歴機能で過去の会話を確認できる
🚀 使い方
サイトにアクセス：https://ran-lovely-you.github.io/manus-v2
Claude API キーを入力
メッセージを入力して送信
AI から返答が返ってきます
🤖 AI について
Anthropic の Claude API キーを入力すると、AI との会話ができます。

API キー入力欄から有効化
キーはブラウザのローカルストレージに保存（外部送信なし）
有料サービスですが、自分のキーを使用するため、利用料はあなたが管理します
📋 動作環境
モダンブラウザ（Chrome, Safari, Firefox, Edge など）
JavaScript 有効
インターネット接続
📄 ライセンス
このプロジェクトはオープンソースです。
